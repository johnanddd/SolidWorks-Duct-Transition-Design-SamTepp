# SolidWorks-Duct-Transition-Design
A SolidWorks CAD work completed during my engineering internship at Samuel Tepp Associates in Summer 2026.

Overview
Designed two custom HVAC duct transitions in SolidWorks for a commercial centrifugal fan installation during my engineering internship at Samuel Tepp Associates. The models connected the fan to existing ductwork and were documented for inclusion in the customer submittal.

Designs

* Square-to-round fan outlet transition
* Round-to-round fan inlet transition

Engineering work

* Interpreted fan and duct dimensions from engineering drawings
* Verified supplied fan geometry against project blueprints
* Created reference planes and parametric sketches
* Used lofts to transition between differing duct profiles
* Modeled fan/fabrication flange geometry
* Verified mating geometry and installation interfaces
* Maintained smooth interior transition geometry
* Revised geometry based on engineering feedback

Deliverable
Produced rendered and annotated CAD documentation showing how the new transition pieces interfaced with the existing ductwork, flex connector, and fan. The documentation was incorporated into the project submittal package.
